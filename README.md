# Final Task - Digital User Churn Dashboard

## Project Overview
Proyek ini bertujuan untuk menganalisis data penjualan dan churn pengguna dengan menggabungkan beberapa tabel menggunakan Google BigQuery dan memvisualisasikannya ke dalam dashboard.

## Repository Structure
- `create_master_table.sql` : Query SQL untuk membuat/menggabungkan master table dari data transaksi, produk, dan pelanggan.
- `README.md` : Dokumentasi proyek.

## SQL Query Highlights
Query SQL dalam proyek ini melakukan join antara tabel:
- `orders`
- `customers`
- `products`
- `product_category`
